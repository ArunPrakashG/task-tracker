# F3 Projects API

## Summary

Create, list and delete projects under `/api/v1/projects`. Deleting a project cascades to its tasks through the database foreign key. Responses use the common envelope from F1.

## In scope

- `POST /api/v1/projects` body `{name, description?}`: 201, returns the project. `name` is trimmed, 1 to 120 characters. Duplicate name returns 409 `PROJECT_NAME_CONFLICT` with `field` `name` (catch the unique violation, do not pre-check only). Decorate with `@rate_limit()` and declare `request: Request`.
- `GET /api/v1/projects`: 200, all projects ordered by `created_at` descending (then `id`).
- `DELETE /api/v1/projects/{project_id}`: 204 with no body, deleting the project and its tasks via the database cascade. Unknown id returns 404 `PROJECT_NOT_FOUND`. A non-UUID id returns 422 `VALIDATION_ERROR` with `field` `project_id`.
- Project response shape: `{id, name, description, created_at}`.
- `app/services/project_service.py` holds the logic; the route is thin and fully async.

## Out of scope

- Updating a project, pagination of projects, the tasks and summary routes.
