# F11 OpenTelemetry on summary (stretch)

## Summary

Stretch goal, built last and only if time remains. Adds an OpenTelemetry span around the summary endpoint's database query showing how long the query took. Telemetry is off by default and has no effect on behaviour when disabled.

## In scope

- Add `opentelemetry-api` and `opentelemetry-sdk`.
- Replace the F1 `setup_telemetry(app)` stub in `app/core/telemetry.py`. Controlled by `OTEL_ENABLED` (default false). When enabled, configure a tracer provider with a console exporter by default and an OTLP exporter when `OTEL_EXPORTER_OTLP_ENDPOINT` is set. Expose `get_tracer()`.
- In `app/services/summary_service.py`, wrap the aggregate query in a span `summary.db_query` with attribute `db.duration_ms` (float), as a child of a `projects.summary` span covering the service call.
- When disabled no spans are recorded and the endpoint behaves exactly as in F5.

## Out of scope

- Tracing other endpoints, metrics, logs, a collector in Compose.
